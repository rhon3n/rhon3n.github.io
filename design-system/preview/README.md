# Preview manifest

Review the system in this order:

1. `colors-primary.html` checks canonical color roles and contrast pairs.
2. `typography-specimens.html` checks the Archivo Black and Source Sans 3 hierarchy.
3. `spacing-tokens.html` checks the four-pixel scale and varied section rhythm.
4. `radius-shadows.html` checks square geometry and interaction-only hard shadows.
5. `components-buttons.html` checks actions, fields, tags, focus, and hover states.
6. `brand-assets.html` visibly loads all three preserved project images.
7. `applied-portfolio.html` embeds the complete responsive UI kit.

`preview.css` provides only the ruled review-card shell. Component and foundation behavior remains visible within each focused card.
