- Project-use status: original generated asset created for Joel Rhine's portfolio; no stock or third-party visual source was used.

It prohibited visible brands, readable text, cafe lifestyle, generic programmer desks, RGB/cyberpunk lighting, floating UI, duplicated tools, and implausible wiring.
