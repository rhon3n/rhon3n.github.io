## A browser-based visual tool

Shader Studio pairs a live WebGL2 preview with adjustable shader and media-processing layers. It exports stills, animations, and saved project settings.

## Media stays local

Source media stays in the browser. Browser graphics and media APIs make it possible to explore effects without uploading files first.

## Save what works

Effects can be combined and saved as project settings, so an experiment can be revisited instead of rebuilt from scratch.
