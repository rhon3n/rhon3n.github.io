## A visual tool in the browser

Shader Studio combines a live WebGL2 preview with configurable shader and media-processing layers. It can export stills, animations, or reusable project settings.

## Local-first media

Source media stays in the browser. The tool uses browser graphics and media APIs to make an expressive workflow immediate without turning uploads into a dependency.

## From experiment to reusable system

The interface exposes a growing set of effects while preserving combinations as project settings. That makes visual exploration repeatable rather than disposable.
